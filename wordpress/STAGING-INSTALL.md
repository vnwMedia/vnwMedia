# Staging installation — not a production launch

Target: redesign.vnwmedia.net ONLY.

1. Review installed plugins and the security warnings on the cloned staging installation. Do not publish old vulnerable plugins or the old theme with this conversion. Do not change other Hostinger sites.
2. In staging WordPress: Appearance > Themes > Add New > Upload Theme. Choose the vnw-media ZIP. Upload does not require deleting the old theme.
3. After the plugin/security review, activate VNW Media on staging only.
4. Open Appearance > VNW Media Setup and click Import approved website. This adds the new content and selects its homepage. It does not delete old pages/posts; reruns skip existing imports.
5. Check the site, navigation, articles, forms, mobile layouts and links. If .html links return 404, open Settings > Permalinks and Save Changes.
6. Configure authenticated WordPress mail on staging. Confirm delivery to contactus@vnwmedia.com with a clearly labelled test inquiry. No inbox-delivery verification has been completed yet.
7. Keep staging inaccessible to search engines and protect it with Hostinger staging access controls. Do not publish until review is complete.

The old-site backup was declined. This package is the new design, not a backup of the old vnwmedia.net website. Production changes have not been made.
