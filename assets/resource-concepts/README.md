# Resources concept previews

Ten new resources/blog concepts replace the former resource-option-11 through resource-option-18 pages. Start at resources.html to compare them, or open resource-option-01.html through resource-option-10.html.

The thumbnails are browser screenshots of the actual concepts, not mockups. All photographs reuse the website's locally stored service-hero assets. No new generated imagery, illustration, or icon assets were added.

Each concept includes topic filtering, text search, draft article previews in an accessible dialog, and links to the three existing resource guides. Draft text is explicitly labeled and intended to demonstrate the blog experience rather than claim publication.

Validation: all ten concepts checked at 1440, 1024, 768, and 390 pixels; image loading, document overflow, filters, empty search state, article opening and Escape dismissal checked. Gallery thumbnails and mobile gallery layout checked.
