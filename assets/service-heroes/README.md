# Service hero photographs

23 original photorealistic hero scenes created with the built-in image generation tool for the service pages. These are illustrative workplace scenes, not photographs of clients or evidence of campaign results.

Each optimized JPEG is approximately 3:1, with people and screens composed toward the right and room for existing HTML copy on the left. The website applies its existing dark overlay and responsive focal positioning. Original service copy, banner dimensions, and tickers are preserved.

See `prompts.json` for the exact generation prompt and asset filename for each service.
