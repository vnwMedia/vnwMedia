# Homepage hero image concepts

Five original photographic hero directions generated with the built-in OpenAI image-generation workflow for `home-hero-image-options.html`.

All prompts requested a cinematic 16:9 homepage background, realistic people and environments, quiet left and right zones for the existing copy and lead form, compatibility with a dark overlay, and no logos, readable text, or watermarks.
